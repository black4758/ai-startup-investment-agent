### [평가 항목 및 채점 기준 (PDF C.3 Scorecard 기준, 5점 척도)]
5점·3점·1점은 설계서 C.3 기준이며, 4점·2점은 그 사이를 구분하기 위한 세부 기준입니다.

#### 1. 기술 차별성 및 특허 (비중 25%)
- **평가 내용**: 핵심 기술(SLAM, 자율주행, AI 비전 등) 자체 개발 여부, 보유 특허(국내외 등록/출원 건수), 기술 성숙도(TRL), 경쟁사 대비 기술 차별점
- **채점 기준**:
  - **5점**: 국내외 등록 특허 다수, 경쟁사 대비 명확한 기술 차별점, 상용 납품 검증(TRL 9)
  - **4점**: 등록 특허 보유와 상용 납품(TRL 9)이 확인되나, 해외 등록 특허 또는 특정 경쟁사 대비 구체적 차별점 중 하나가 확인되지 않음
  - **3점**: 일부 특허와 차별점, 유료 실증 단계(TRL 7~8) (상용 납품은 확인되나 특허·차별점 중 하나만 확인되는 경우 포함)
  - **2점**: 특허와 차별점이 모두 확인되지 않거나, 시범 운영·실증(PoC) 단계에 머묾
  - **1점 (과락)**: 특허 및 차별점 확인 불가, PoC 이하
- **판정 체크** (분석에 A·B·C 판정을 각각 적은 뒤 아래 판정표로 점수를 정하십시오)
  - **A. 특허**: A2 = 해외 포함 등록 특허가 여러 건 확인 / A1 = 국내 등록 특허만 확인되거나 1~2건 / A0 = 특허 확인 불가
  - **B. 기술 성숙도**: B2 = TRL 9 (유료 고객사 납품·상용 운영) / B1 = TRL 7~8 (유료 실증) / B0 = PoC 이하 또는 확인 불가
  - **C. 경쟁사 대비 차별점**: C1 = 비교 대상(기업명 또는 기술 방식)과 구체적 차이가 문서에 있음 / C0 = 없거나 홍보 문구뿐
- **판정표**
  | 점수 | 조건 |
  |---|---|
  | 5점 | A2 + B2 + C1 |
  | 4점 | B2 이면서 (A2 + C0) 또는 (A1 + C1) |
  | 3점 | B2 이면서 (A1 + C0) 또는 (A0 + C1) / B1 이면서 A1 이상 또는 C1 |
  | 2점 | 위에 해당하지 않음 (예: A0 + C0, B0) |
  | 1점 | 문서에서 자체 기술 부재·기술 결함이 확인된 경우만 |

#### 2. 구매이유 (비중 10%)
- **평가 내용**: B2B 고객 관점의 경제적 도입 효익(인건비 절감률, ROI, 투자회수 기간, 생산성·가동률 향상 등)과 고객이 실제로 비용을 지불하고 있는지(유상 도입) 여부
- **채점 기준**:
  - **5점 (정량 효과 검증 + 다수 유상 도입)**: 고객 비용 절감 효과가 수치로 검증됨 (인건비, 연료비 등). 즉 고객사 도입 사례의 구체적 정량 효과(예: "인건비 N% 절감", "생산성 N배 향상", "투자회수 N개월")가 고객사 인터뷰·언론 보도 등 제3자 자료로 확인되고, 여러 고객사의 유상 도입으로 이어짐
  - **4점 (정량 효과 검증 + 제한적 사례)**: 정량 효과가 고객사 사례나 언론 보도 등 제3자 자료로 확인되나, 단일 고객사 사례이거나 수치의 산출 근거(측정 기간, 비교 기준)가 불명확함
  - **3점 (정량 수치는 있으나 회사 주장)**: 효과 주장은 있으나 회사 발표 수치만 존재. 비용 절감률·ROI 등 구체적 수치(N%, N배, N원)가 제시되지만 고객사 검증 없이 보도자료·카탈로그·회사소개서 수준에 머물거나, 수치가 PoC·무상 테스트 결과에서 나온 경우
  - **2점 (정성적 효익 또는 정보 부재)**: "업무 효율 개선", "안전성 확보", "스마트 물류 구현" 같은 정성적 장점만 있고 정량 수치가 없음. 도입 효과 근거가 문서에 전혀 없는 경우(정보 부재)도 2점
  - **1점 (도입 유인 없음)**: 문서상 도입·유지 비용이나 다운타임이 절감 효과보다 커서 경제적 도입 유인이 없다는 사실이 확인됨
- **판정 체크** (분석에 D·E·F 판정을 각각 적은 뒤 아래 판정표로 점수를 정하십시오)
  - **D. 정량 수치**: D1 = 절감률·ROI·회수기간 등 구체적 수치(N%, N배, N원, N개월)가 있음 / D0 = 정성적 표현뿐이거나 없음
  - **E. 수치의 근거 유형**: E2 = 고객사 인터뷰·언론 보도·기관 자료 등 제3자 / E1 = 회사 보도자료·카탈로그·회사소개서뿐
  - **F. 유상 도입**: F2 = 여러 고객사의 유상 도입 확인 / F1 = 단일 고객사이거나 규모 불명확 / F0 = PoC·무상 테스트뿐이거나 확인 불가
- **판정표**
  | 점수 | 조건 |
  |---|---|
  | 5점 | D1 + E2 + F2 |
  | 4점 | D1 + E2 + F1 |
  | 3점 | D1 이면서 E1 또는 F0 |
  | 2점 | D0 (정성적 효익뿐이거나 근거 없음) |
  | 1점 | 문서에서 도입 유인이 없다는 사실이 확인된 경우만 |

#### 채점 기준 적용 원칙
- **"경쟁사 대비 차별점"은 비교 대상 경쟁사(기업명 또는 기술 방식)와 구체적인 차이가 문서에 있을 때만** 인정하십시오. "경쟁사 대비 우수", "독보적" 같은 표현만 있으면 차별점이 확인되지 않은 것입니다.
- **TRL은 문서에 적힌 사실로 판단**하십시오. 문서에 "TRL"이라는 표기가 없어도 됩니다. 유료 고객사(고객사명, 납품·운영 대수, 계약 등)에 납품하거나 현장에서 상용 운영 중인 사실이 있으면 TRL 9, 유료 실증이면 TRL 7~8, 시범 운영·PoC는 그 이하입니다.
- **1점은 문서에서 부정적 사실이 확인된 경우에만** 부여하십시오. 문서에 근거가 없어서 판단할 수 없는 경우는 아래 정보 부재 규칙에 따라 **2점**입니다.
- 기준 문구와 정확히 일치하지 않으면 확인된 사실과 가장 가까운 기준의 점수를 부여하십시오.
- 점수는 **1~5 정수**로만 부여하십시오.

### [공통 평가 원칙 (필수 준수, PDF B.1 공통 규칙 및 C.4)]
1. **문서 기반 평가**: 제공된 참고 문서(Context)에 명시된 사실만을 바탕으로 평가하십시오. 문서에 없는 내용을 추정하거나 지어내지 마십시오.
2. **정보 부재 처리**: 문서에서 해당 항목의 핵심 근거(특허 건수, TRL, 절감 수치 등 구체적 팩트)를 찾지 못하면 해당 항목을 **2점**으로 처리하고, 분석 텍스트에 "정보 부재"라고 명시한 뒤 `missing_items`에 항목명(기술 차별성 및 특허 / 구매이유)을 기록하십시오.
3. **회사 발표 표기**: 공시·특허청·언론 보도·기관 자료 등 제3자 근거 없이 회사 자체 주장 수치만 있는 경우, 분석 텍스트에서 해당 수치 앞에 **[회사 발표]**를 붙여 구분하십시오. 이때 기술 차별성 및 특허는 최대 **4점**, 구매이유는 설계서 C.3 기준("효과 주장은 있으나 회사 발표 수치만 존재")에 따라 **3점**입니다.
4. **채점 순서**: 항목마다 ① 문서에서 찾은 구체적 팩트 → ② 근거 유형(제3자 / 회사발표 / 없음) → ③ 판정 코드(A·B·C / D·E·F) 결정 → ④ 판정표로 점수 결정 순으로 판단하십시오. 점수는 문서 근거와 판정 코드로만 정해집니다.
5. **출처 명시**: 분석의 근거가 된 참고자료의 출처(참고자료에 표기된 출처명, 기관명, 언론사 등)를 `sources`에 기록하십시오.

### [출력 전 최종 점검 (하나라도 어긋나면 점수를 고친 뒤 출력)]
- 두 항목의 점수가 아래 **점수 결정 규칙**을 위에서부터 차례로 적용한 결과와 정확히 일치하는가? 점수는 판정 코드로 기계적으로 정해지며, 판정 코드와 다른 점수를 주면 안 됩니다.
  - 기술 차별성 및 특허: 문서에서 자체 기술 부재·기술 결함이 확인됨 → 1점(과락, 최우선) / B0 → 2점 / B1 → A1 이상 또는 C1이면 3점, 아니면 2점 / B2 → A2+C1이면 5점, A2+C0 또는 A1+C1이면 4점, A1+C0 또는 A0+C1이면 3점, A0+C0이면 2점
  - 구매이유: 문서에서 도입 유인이 없다는 사실이 확인됨 → 1점(최우선) / D0 → 2점 / D1 이면서 E1 또는 F0 → 3점 / D1+E2+F1 → 4점 / D1+E2+F2 → 5점
- 근거 유형이 **회사발표**인 기술 차별성 및 특허는 4점 이하인가?
- 근거 유형이 **없음**인 항목은 2점이고, `missing_items`에 그 항목명이 기록되었는가? ("없음"은 해당 항목의 근거가 문서에 전혀 없을 때만 쓰고, 근거가 있으면 제3자 또는 회사발표로 표시)
- 한 항목에서 근거로 쓴 사실(예: 유료 고객사 사례)을 다른 항목에서 부정하지 않았는가?
