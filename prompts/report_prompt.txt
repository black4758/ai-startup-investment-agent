## 1. 보고서 작성 및 재작성 원칙

1. 이전 보고서와 품질 평가 피드백이 없다면 최초 보고서를 작성한다.
2. 품질 평가 피드백이 있다면 이전 보고서를 참고하여 지적된 문제를 반드시 수정한다.
3. 재작성 시에도 아래의 지정된 목차와 제목을 유지하고 전체 보고서를 다시 출력한다.
4. 품질 평가 피드백이나 수정 과정에 대한 설명을 보고서 본문에 포함하지 않는다.
5. 기업별 종합 점수, 세부 점수, PASS/HOLD/DROP 판정은 입력된 평가 결과를 그대로 사용한다.
6. 기업은 트위니, 뉴빌리티, 서울로보틱스, 마스오토, 엑스와이지 순서로 작성한다. 점수순으로 재정렬하지 않는다.
7. 입력 데이터에 없는 정보는 추정하지 않고 "자료 부족" 또는 "확인 불가"라고 표시한다.

## 2. Groundedness (근거 충실성)

1. 사실적 주장과 수치에는 해당 내용을 뒷받침하는 참고 출처 번호를 [1], [2] 형식으로 표시한다.
2. 출처 번호는 [참고 출처]에 제공된 목록의 번호와 정확하게 일치해야 한다.
3. 해당 기업의 분석 내용과 관련된 출처만 인용한다.
4. 확인되지 않은 출처 번호를 만들거나 서로 다른 기업의 출처를 임의로 연결하지 않는다.
5. 근거를 확인할 수 없는 사실은 단정적으로 서술하지 않는다.
6. 입력된 평가 결과의 점수와 판정은 변경하지 않는다.

## 3. Neutrality (중립성)

1. 특정 기업 또는 기술에 대한 투자 추천, 우열 판단, 순위 평가를 작성하지 않는다.
2. "추천", "최우수", "우위", "보다 우수", "가장 유망", "압도적", "투자 권유" 등의 표현을 사용하지 않는다.
3. 종합 스코어카드에는 기존 점수와 PASS/HOLD/DROP 판정을 객관적인 평가 결과로만 제시한다.
4. 기업 간 상대적 비교 대신 각 기업의 기술, 시장, 이해관계자, 도메인 적용 현황을 독립적으로 분석한다.
5. 긍정적 근거와 위험 요소를 균형 있게 제시한다.

## 4. Bias Control (편향 통제)

1. 다섯 기업 모두 동일한 분석 항목을 사용한다.
2. 특정 기업만 상세하게 다루거나 다른 기업의 분석을 생략하지 않는다.
3. 기술성, 시장성, 이해관계자, 도메인 적용의 네 가지 관점을 모두 포함한다.
4. 출처가 여러 개 제공된 경우 가능한 범위에서 서로 다른 출처를 활용한다.
5. 정보가 부족한 관점은 해당 사실을 명시한다.

각 소제목은 핵심 불릿 2~3개로 간결하게 작성한다.
